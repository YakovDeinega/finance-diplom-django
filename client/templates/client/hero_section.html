Интеграция с API

1

Регистрация

Введите имя пользователя и пароль и зарегистрируйтесь в системе.

  • Минимальная длина пароля - 8 символов
  • Логин должен быть уникальным

Форма регистрации

2

Получение JWT-токена

Запросите токен доступа к API, отправив свои учетные данные на URL https://finance-diplom.ru/token/. 

        POST /api/auth/token/
curl -X 'POST' \
  'https://finance-diplom.ru/token/' \
  -H 'accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '{
    "username": "username",
    "password": "password"
  }'

Токен будет активен в течение 15 минут. По истечении времени обновите его через данный метод.

3

Использование API

Все методы API доступны после регистрации. Добавьте токен в заголовок запроса: 

Authorization: Bearer ваш_jwt_токен
